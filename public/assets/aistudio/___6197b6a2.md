## 整体语感
- 句长分布：短句多，但长短交替分明。战斗、紧张场面用短句甚至单字句（「——不对。」「没有。」），心理独白与设定解说用中长句层层铺陈。短句负责节奏与冲击，长句负责信息与情绪堆叠。一句概括：冷静克制的第一人称，靠句长伸缩控制紧张度。
  - 依据：原文锚点
- 标点习惯：破折号高频，用于转折、插入补充与内心自我否定（「——不对。」「——我很害怕」）；省略号高频，用于迟疑、恐惧与留白（「呼……」「没有……退出的按钮？」）；句号短促，段落内常以多个短句连缀推进。
  - 依据：原文锚点
- 段落节奏：平均段长短，单段常是一到三个动作或一个心理活动；对话与动作交替出现，几乎每段对话都配一个动作或心理补充，避免纯对话堆叠。
  - 依据：原文锚点

## 对话技法
- 潜台词模式：① 问非所答（克莱因回「桐人……但那家伙会乱动啊」避重就轻）；② 语气反差（轻松玩笑下藏不安：「怎么可能，仔细找找」）；③ 信息隐瞒（桐人对妹妹、对等级的说一半藏一半）。对话后面常紧跟一句揭示真实心理的独白。
  - 依据：原文锚点
- 对话标签习惯：说话动词多样但克制（说、叫、低语、嚅嗫、回话），大量用「动作+对话」替代「XX说」；角色语气差异明显，桐人冷静吐槽、克莱因聒噪直率、亚丝娜傲娇直接。
- 角色语气区分：桐人口头禅是自嘲式的自我否定（「笨蛋」「开玩笑」）；克莱因语气夸张聒噪（「痛痛痛……这家伙……」）；亚丝娜直接而傲娇（「才不是那么回事」）。

## 情绪交替模式
- 章内基调切换：紧张↔轻松、热血↔温馨频繁切换。第3章同一章内从搞笑（克莱因战山猪）切到悬疑（登出按钮消失）再到压抑（世界失去原貌），切换约 2-3 次，用对话或环境描写做转场。
  - 依据：已有资料
- 跨章基调周期：已拆范围内第 1-42 章基调序列呈现「压抑/恐怖（开幕）→ 轻松/甜（桐亚）→ 紧张/悲壮（决战）→ 温馨/悲伤（外传）」的宏观弧线；局部约每 3-5 章一次情绪反转（如第 15 章悲伤、第 16 章恐怖、第 17-18 章甜）。不足 20 章规律时以剧情单元为节奏单位。
- 喜剧↔重击的转场手法：用「现实牵挂」做转场（如「比萨变冷」「登出按钮」），让喜剧瞬间转入恐怖；用「环境描写」收束情绪（如片段 D 用夕阳美景反衬「世界失去原貌」的压抑）。

## 可借鉴技巧（从 拆文报告.md 直接引用）
- 写法技巧 Top 5：
  1. 设定内嵌：硬设定通过对话/独白交代，不干瘪说明。
  2. 异常渐层累积：从生活化小异常写起，逐步渗入恐惧。
  3. 精确数字冲击：用「213人已死」等数字制造真实感。
  4. 远伏笔回收：跨章伏笔有仪式感的揭示时刻。
  5. 身体反应代替心理描写：用生理细节写恐惧与紧张。
- 可借鉴套路 Top 3：
  1. 死亡游戏开幕反转：情绪从好奇到恐惧再到求生悬念。
  2. 迟来追悔与遗言救赎：用逝者遗言完成情感闭环。
  3. 单恋释怀：配角体面退出、自我成长。

## 分层模仿建议
- 基础层（必学）：短句控制节奏、破折号/省略号的转场用法、对话配动作、用精确数字写真实感、用生理反应写情绪。只学表达习惯，不复制原句。
- 进阶层（结构）：远伏笔（异常速度→身份揭晓）、设定内嵌（教学对话交代世界）、章末反转预告（「世界失去原貌」）、感情线嵌在主线里交替推进。替换人物/场景/道具后再使用。
- 适配层（适合当前项目）：死亡游戏/末世/规则怪谈题材可直接套用「异常累积+致命规则宣告」结构；主角创伤+遗言救赎适合感情向作品；VR/网游题材可借鉴「能力来源=最大敌人」的反派设计。不搬运茅场晶彦、SAO、二刀流、黑猫团等专名与标志性台词。

## 原文锚点片段

> 每片段 300-500 字，供写正文时当范例。优先复用旧文风、黄金三章或批次中已保存并带定位的连续原句；没有有效样本时按 `chapter_index.csv` 定点读取。模仿手法，不抄字句。

### 片段 A — 基调：紧张/热血
**出处**：第 2 章（行 13-44）
**示范点**：短句节奏 / 战斗动作分解 / 专业术语内嵌

```
闪烁着深灰色光芒的剑尖，浅浅地划过我的肩膀。那固定显示在视线左上角的细长横线，略微缩短了长度。同时，似乎有只冰冷的手掌，抚摸过我胸口深处。横线——那称为HP条的蓝色条状物，可以看出我的生命残值。……就算我眼前所见全部都是虚拟的立体影像物件，减少的也只是数值化的生命值，但我现在的确是赌上自己的性命在战斗。从赌上性命这点来看，这场战斗真是相当不公平。因为，眼前的“敌人”——这除了拥有闪耀着光芒的深绿鳞片皮肤与长手臂外，还有着蜥蜴头与尾巴的半人半兽怪物，不只外表不是人类，甚至没有真实的生命。它只不过是不论被杀掉多少次，都可以由系统无限重生的数据档案集合体。——不对。目前，操纵这只蜥蜴人的AI程式正在观察、学习我的战斗方式，用以不断提升自己的应对能力。但这些学习档案，在该个体消灭后便会重置，而且不会反馈到下次出现在这个区域的同种个体上。
```

### 片段 C — 基调：紧张/悬疑
**出处**：第 3 章（行 170-211）
**示范点**：异常渐层累积 / 现实牵挂渗入恐惧

```
“这是怎么回事……没有退出的按钮？”听到这句话，我停下手上的动作，抬起头来说道：“没有按钮……怎么可能？仔细找找。”……“真的找不到。你也找找看嘛，桐人。”“我不是说了，怎么可能会有那种事嘛……”我边叹气边嚅嗫道。……我用相当熟练的动作把手指移到最下方——这一刻，我全身的动作停了下来。没有。正如克莱因所说的，封闭测试时——不对，今天下午一点登录游戏时还确实在那里的退出按钮，现在却消失得一干二净。
```

### 片段 D — 基调：压抑/悬疑
**出处**：第 3 章末（行 247-253）
**示范点**：环境描写收束情绪 / 反讽预告

```
艾恩葛朗特的四季是依据现实世界来演变的，所以现在也与现实世界一样刚刚进入冬天。我深深地吸了一口假想的干冷空气后，一边感受着肺里假想的空气一边把视线往上移。数百米的遥远上空，第二层的底部被一片紫色云雾给笼罩着。……时间已经超过五点半，我眯起眼睛窥看被夕阳染成一片赤红的天空。斜射的太阳光让广阔的草原闪耀着金色光芒，即使现在身处异常状况，我依然因这美丽的假想世界而感动得说不出话来。但在这之后。这个世界却永远失去了它原本的面貌。
```

> 本书锚点覆盖紧张/热血、轻松/搞笑、紧张/悬疑、压抑/悬疑四种基调，热血与温馨样本偏少，悲伤/温馨基调可参考章节摘要中的表达层观察。

## 不建议模仿
- 设定解说偶有冗长（如第 3 章 NERvGear 机制的长段科普），在现代网文里会拖节奏；写书时宜拆散到对话与动作中，避免连续大段说明。
